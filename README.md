# Команда и построение отношений с покупателями

Репозиторий для нового стиля презентаций: тёмный минималистичный формат с крупной типографикой, карточками, градиентными акцентами и сторителлингом через цифры.

## База

- Формат: 16:9, Full HD 1920×1080.
- Основная тема: команда, лидерство, отношения с покупателями, адаптация, обратная связь, корпоративная жизнь.
- Визуальный тон: уверенный, технологичный, строгий, без перегруза мелкими деталями.
- Слайды строятся на крупных заголовках, сильной сетке, больших числах и мягких тёмных карточках.

## Ключевые файлы

- `style/presentation-style.md` — подробный гайд по стилю.
- `style/design-tokens.json` — цвета, размеры, сетка, типографика.
- `prompts/slide-agent.md` — инструкция для генерации новых слайдов в этом стиле.
