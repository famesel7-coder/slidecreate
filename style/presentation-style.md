# Style Guide — тёмная презентация про команду и отношения

## 1. Общий характер

Стиль презентации — тёмный, минималистичный, технологичный. Он строится не на иллюстрациях, а на сильной типографике, больших числах, строгой сетке, мягких карточках и редких градиентных акцентах.

Ключевое ощущение: уверенный внутренний корпоративный доклад, где важны люди, процессы, лидерство, обратная связь и понятные результаты.

## 2. Формат

- Размер слайда: 1920×1080, 16:9.
- Без декоративного шума и мелких деталей.
- Много воздуха, крупные блоки, минимум элементов.
- Основной фон почти чёрный.
- Акцентный градиент используется как атмосфера, а не как декоративная заливка всего слайда.

## 3. Цвета

### Основные

- Почти чёрный фон: `#08090A` / `#050607`.
- Глубокий зелёно-чёрный: `#010B0A`.
- Тёмная карточка: `#1D1E1F`.
- Вторичная карточка/плашка: `#2B2F30`.
- Верх карточки/активная плашка: `#424849` / `#555758`.
- Белый текст: `#FFFFFF`.
- Вторичный текст: `#DCDDDD`.
- Приглушённый текст/цифры: `#626364` / `#3A3B3C`.

### Акцентный градиент

Использовать редко, крупными мягкими пятнами:

- Бирюзовый: `#02B5C7`.
- Аква: `#00D6E6`.
- Зелёный: `#00D05A`.
- Изумрудный: `#02866E`.
- Глубокий зелёный: `#084031`.

Градиент чаще всего идёт из правого нижнего угла или через нижнюю часть слайда: чёрный → тёмно-зелёный → бирюза → зелёный.

## 4. Типографика

### Шрифт

Основной шрифт должен быть геометрическим гротеском: `Inter`, `Graphik`, `Suisse Intl`, `Manrope`, `Arial` как fallback.

### Заголовки

- Крупные, белые, плотные.
- Начертание: Bold / ExtraBold / Black.
- Межстрочный интервал плотный: 0.9–1.05.
- Главные заголовки могут занимать 2–4 строки.
- Верхний регистр используется для сильных смысловых акцентов: «КОДЕКС ЛИДЕРА», «ЧТО ИЗМЕНИЛИ».

### Текст

- Вторичный текст — белый или светло-серый.
- Не мельчить: текст должен быть читаемым с экрана.
- Формулировки короткие, без длинных абзацев.
- Лучше 2–4 строки в блоке, чем плотный текст.

## 5. Сетка и композиция

### Базовая сетка

- Поля: 60–70 px от краёв.
- Межколоночные отступы: 35–55 px.
- Карточки и смысловые блоки выравниваются по одной вертикальной логике.
- Допустимы крупные пустые зоны — это часть стиля.

### Типовые композиции

1. **Титульный слайд**
   - Большой заголовок слева снизу/по центру левой половины.
   - Подзаголовок ниже, меньше в 2–3 раза.
   - Справа и снизу — мягкий градиент.

2. **Навигация / структура**
   - Центральный большой заголовок.
   - Вокруг — карточки с номерами и темами.
   - Карточки могут иметь разную высоту, но должны выглядеть как единая система.
   - Внизу справа — короткая подпись раздела.

3. **Слайд с метрикой**
   - Слева — большой заголовок и огромная цифра.
   - По центру — поясняющие смысловые блоки.
   - Справа — вертикальная колонка карточек со статистикой.

4. **Слайд изменений / выводов**
   - Слева крупная тёмная панель с заголовком.
   - Справа сетка 2×3 из текстовых блоков.
   - Тонкие разделительные линии сверху/снизу каждого блока.
   - Большие полупрозрачные номера на заднем плане.

## 6. Карточки и плашки

- Скругление: 28–36 px.
- Заливка: тёмно-серая или мягкий градиент внутри карточки.
- Активная карточка может быть светлее остальных.
- Тени почти не используются; объём создаётся разницей тонов.
- Внутренний отступ карточки: 40–50 px.
- Номер карточки — маленький, тонкий, сверху слева.
- Заголовок карточки — крупный, жирный, 2–3 строки максимум.
- Подпись под карточкой — отдельной плашкой или нижним блоком.

## 7. Числа

Числа — важный визуальный приём.

- Огромные: 170–320 px.
- Вес: Light / Regular для цифр, Bold для подписи.
- Можно использовать градиентную обводку/заливку для главной цифры.
- Второстепенные номера можно делать полупрозрачными: `#3A3B3C`.
- Число должно занимать роль визуала, а не просто подписи.

## 8. Линии и разделители

- Тонкие линии 1–2 px.
- Цвет: `#2C2D2E`, `#4A4B4C`, иногда белый с прозрачностью.
- Используются для разделения смысловых блоков.
- Не строить сложные схемы из линий — только структурные разделители.

## 9. Что нельзя

- Не добавлять мелкие иконки без необходимости.
- Не перегружать слайд иллюстрациями.
- Не использовать яркий градиент на каждом элементе.
- Не делать много мелкого текста.
- Не ставить тяжёлые декоративные рамки.
- Не использовать разноцветную палитру вне бирюзово-зелёного акцента.

## 10. Правило новых слайдов

Каждый новый слайд должен отвечать на один вопрос: какой один главный смысл зритель должен запомнить?

Сначала строим иерархию: главный заголовок → крупная цифра/ключевой блок → 2–6 коротких тезисов → акцентная подпись. Только после этого добавляем графику или градиент.
